# Issue tracker

**Tipo:** markdown local

Issues e tickets gerados pelas skills (`to-spec`, `to-tickets`, etc.) neste hub vivem em:

```
.scratch/issues/
```

Convenção sugerida:

- Um arquivo por issue: `.scratch/issues/<id>-<slug>.md`
- Specs: `.scratch/issues/<id>-spec.md` ou pasta `.scratch/specs/`
- Tickets com edges de bloqueio descritos no corpo do markdown

Quando o hub tiver remote no GitHub e o time preferir Issues nativas, atualize este arquivo e rode de novo o setup das skills se necessário.
